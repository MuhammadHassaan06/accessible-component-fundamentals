# Accessible Component Fundamentals

This project is a React + TypeScript playground for building accessible components from scratch.

The component implementations will be added under `playground/` as the assignment progresses.

## Scripts

- `npm run dev` starts the Vite development server.
- `npm run build` runs the TypeScript build and creates a production bundle.
- `npm run lint` checks the project with ESLint.
